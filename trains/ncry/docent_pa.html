NCRy Docent System Overview

2026-04

The following is a short technical description of the PA docent system components, to understand the system as a whole. This is not a user documentation.

All components, from top to bottom:

1- QSC Q-SYS Core Nano Network Processor

2- Araknis Networks 210 Series PoE Switch

3- XLR Fixed Microphone Input

4- Shure QLXD4 (Wireless Microphone input)

5- Denon DN-500CB

6- Furman PL-PLUS C (Power Conditioner)

7- Upper Drawer

8- Lower Drawer

9- Ashly CA-1.04

10- Juice Goose SCV Series UPS

1- QSC Q-SYS Core Nano Network Processor

Role: Network audio processor. All audio is from a local LAN (digital, not analog).

https://www.qsys.com/products-solutions/q-sys/audio-io-peripherals/qio/

QSC Q-SYS QIO-ML4i Peripheral : Network input extender (4 mic/line audio inputs)

QSC Q-SYS QIO-L4o Peripheral : Network output extender (4 lines outputs)

https://www.qscaudio.com/resource-files/productresources/dn/qio_series/q_dn_qsys_qio_audio_io_expanders_specs.pdf

2- Araknis Networks 210 Series PoE Switch

Model: ??V-R-8-PoE

Role: 8-Port Managed Gigabit Switch with PoE+

This is a network switch to plug all the digital audio equipment together.

“OvrC Enabled” means it can be managed remotely.

3- XLR Fixed Microphone Input

This is the fixed mic input using a balanced XLR plug.

This is very likely wired to the QIO-ML4i which happens to have mic/line inputs (which explains why it’s located just below it).

It appears as an input (#3 I think) on the controlling iPad.

4- Shure QLXD4 (Wireless Microphone input)

Role: Digital Wireless Receiver for the microphone.

https://www.shure.com/en-US/products/wireless-systems/qlx-d_digital_wireless/qlxd4

5- Denon DN-500CB

Role: This is a CD player.

https://www.denonpro.com/products/dn-500cb

On top of CD, it has the following inputs:

  • Bluetooth. A party could provide music via a phone or tablet bluetooth.
  • USB: A party could provide music via a USB drive with music files.
  • Aux input: There’s a 3.5 mm headphone jack input on the right bottom of the unit.
  • The input is selected using the “Source” button on the very left.

6- Furman PL-PLUS C (Power Conditioner)

Role: Linear Filtering Power Conditioner. It “cleans” the AC signal to avoid interferences (aka buzzing… I’m oversimplifying but that’s all we need to know here).

https://furmanpower.com/products/pl-plusc

Interesting bit: the 2 round “F” knobs are not knobs at all but actually retractable LED lights that can be used to illuminate the rest of the AV equipment, on purpose for that kind of usage.

7- Upper Drawer

Storage for wireless mic, battery charger, iPad.

I didn’t specifically check which kind of iPad that is. That looks like an 11-inch screen.

Also I didn’t check the model of the wireless microphone. A Shure wireless misc given the charger.

8- Lower Drawer

Storage for Wired Mic.

The wired mic is a Shure SM58.

https://www.shure.com/en-US/products/microphones/sm58?variant=SM58-LC

9- Ashly CA-1.04

Role: 4-channel Power Amplifier

https://ashly.com/amplifier-card/ca1-04/

This is a 4x 1000W amplifier (!).

The 4 channels have different volume (amplification) levels, controlled by the iPad “Ouput” tab.

From left to right:

Channel 1: Car 10040

Channel 2: Car 2473/2474 (the articulated coach likely needs a softer volume)

Channel 3: Coach cars + Caboose

Channel 4: Open Cars

Each vertical column of LEDs corresponds to a channel. On the following picture, the 2nd led “signal” is on for channel 1 and 4 so one would posit that channels 2 and 3 produced no sound.

10- Juice Goose SCV Series UPS

This is an uninterrupted power supply.

https://juicegoose.com/products/scv-series

My guess is that it serves to protect the whole equipment from under/over-voltage, as well as regulate it e.g. during locomotive or generator hookups.

The display is self-explanatory:

  • “ON” / “OFF” turns everything on and off respectively.
  • 118 V is the input voltage (since “input” is highlighted by a rectangle).
