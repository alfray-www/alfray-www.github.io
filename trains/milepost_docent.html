Milepost Docent
[Android App]

2026-05

Milepost Docent is an Android application that automates docent announcements for a heritage railway such as living history museums operating historic steam and diesel trains.

A GPS track is captured that corresponds to a train's scheduled route, and milepost numbers are associated with points along the track. The app automatically computes the train's current milepost based on its location relative to the expected track.

Pre-recorded docent audio segments are then programmed to play automatically at specific mileposts and travel directions as the train progresses on its journey.


Description

The application was designed to provide narration for the Niles Canyon Railway and could easily be adopted to another railway.

The app runs on Android and uses a GPS to find its location. Once the GPS track of the train trip is recorded, milepost numbers are associated with the track. These are then used to automatically play pre-recorded audio when the train reaches the desired mileposts.

To use the app for the Niles Canyon, we run the app on a small Samsung Galaxy tablet. The audio is output to the PA system using a simple jack input to a line amplifier. The tablet has an internal gps, but that requires the tablet to be next to a window. As this is not always possible, the app also supports connecting an external USB GPS receiver which can be mounted away from the tablet.

Usage

The first step is to capture the various audio segments. These were recorded on a laptop, fine tuned with Audacity, and imported into the tablet over USB. Using the “Audio Segments” screen, we register all the audio segments into the app. This step creates references to the audio files which are located on the tablet’s internal memory.

The next step is to record the GPS track. To do this, we use the “Record GPS Track” screen. It needs to run on location. For the NCRy demonstration, recording was started when the excursion train was waiting at the Sunol station. We recorded the train as it traveled to the Niles train station, where we ended the recording. The train then proceeds back to Sunol but we only need to record one leg of the trip.

The “Review GPS Track” is then used. It displays the recorded track with all the GPS coordinates, the engine speed, and a map view. At the very least we need to indicate the Milepost numbers for the start and end station -- all other points are then interpolated.

Using the official NCRy timetable, we can then edit some of the points to adjust their milepost number and to give them specific names. These names are then displayed as “point of interest” under the map. For example for the NCRy track, we add points of interest for the Brightside yard as well as the Farwell and Dresser bridges. These come in handy later when mapping the audio segments to milepost numbers.

The next step is to create a new “Docent Track” based on the GPS track.

At this point, we add “docent triggers” -- these specify which audio segment to play, and when. For each trigger, we give a milepost range, and an optional direction. When the train will be within that milepost range later, in the requested direction, the associated audio segment will start playing.

Each docent track can be either active or inactive. A track will not run when active, and even when active, “enable conditions” indicate when the docent track can start. This allows us to have multiple docent tracks active at the same time, yet only one will be enabled based on specific conditions -- the conditions should be exclusive and such that only one specific track can be enabled at a time. For example for NCRy, a train-of-lights docent track can only be executed during November and December, whereas a regular excursion docent track can only be executed the rest of the year during the week-end. It is expected that several docent tracks will be using the same GPS track and maybe a combination of the same audio segments.

Finally, we’re ready to playback the currently active docent track. The “Playback docent track” screen shows the audio triggers, as well as a live map based on the current GPS location. The milepost number is displayed, as well as the direction of the train. When the train is in a docent trigger range, the associated audio starts playing. Once that segment ends, the next segment is ready to play. A button on the side lets you pause the current recording, or instantly start any other one.

Once a docent track has been created, the app has a simulation mode that lets us test it. The simulation uses the track GPS coordinates and its recorded timing, with an optional speed up when no audio is playing. The NCRy excursion train takes about 30 minutes to complete its track; however, using the simulation mode, we can test the docent track in about 10 minutes.
